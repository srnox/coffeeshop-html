# MAVIX Coffee Company Website 🍵

A modern, responsive coffee company website built with HTML, CSS, and JavaScript. Features a clean design with interactive elements and mobile-first approach.

## Features

- 📱 Fully responsive design
- 🍔 Interactive hamburger menu for mobile devices
- 🎨 Modern grid layout system
- 🌗 Light/dark theme elements
- 🖼️ Image grid sections
- 🔗 Social media integration
- 🎯 Call-to-action buttons
- 📍 Store locator feature

## Customization

The website uses modular CSS classes for easy customization:
- `.bg-primary` - Primary background color
- `.bg-secondary` - Secondary background color
- `.text-xl`, `.text-md`, `.text-sm` - Text size variations
- `.btn-dark`, `.btn-light-outline` - Button styles
- `.grid-col-2` - Two-column grid layout
